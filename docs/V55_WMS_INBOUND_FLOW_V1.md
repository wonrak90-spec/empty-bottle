# V55 WMS 입하실적 기반 공병 입고 흐름 V1

## 1. 설계 기준

공병 입고 프로그램의 관리 기준은 차량이 아니라 다음 WMS 구조를 따른다.

입하실적번호
→ 품목정보
→ 관리번호 / LOT NO / 입하량
→ 포장정보(포장단위 / 포장수 / 순번)
→ 개별 Pallet

차량은 하나의 WMS 입하 물량을 여러 번 나누어 운송할 수 있는 물류 단위이며,
프로그램의 상위 식별키로 사용하지 않는다.

## 3. 중요한 해석

- 약 80 Pallet은 고정된 1회 입고 단위가 아니다.
- 실제 일별 입고 Pallet 수는 품목 조합과 입하량에 따라 달라진다.
- 하나의 품목 관리번호가 28~48 Pallet 정도의 포장수로 구성될 수 있다.
- 하나의 WMS 관리번호 물량이 여러 차량에 나누어 들어올 수 있다.
- 따라서 차량 교체 시 진행률을 초기화하면 안 된다.
- WMS의 "포장수"와 "순번"이 개별 Pallet 관리의 핵심 기준이다.

## 4. 권장 프로그램 구조

### A. 입고 대상 선택

사용자는 당일 WMS 입하 대상에서 입하실적번호 또는 품목 관리번호를 선택한다.

표시:
- 입하일자
- 입하실적번호
- 품목코드
- 품목명
- 관리번호
- LOT NO
- 입하량
- 포장단위
- 포장수
- 순번 범위

예:
까스활명수큐병
관리번호 26004032
포장단위 10,800
포장수 48
순번 0001~0048

### B. WMS 라벨 사전 출력

WMS에서 포장수/순번 범위에 맞게 Pallet 라벨을 미리 출력한다.

프로그램에서는 "선출력 라벨 수"를 작업자가 다시 입력하는 방식보다,
가능하면 WMS 포장수 또는 라벨 순번 범위를 기준값으로 사용한다.

### C. 현장 Pallet 처리

1. 차량 도착
2. Pallet 하차
3. 해당 Pallet에 사전 출력된 WMS 라벨 부착
4. WMS 라벨 OCR/스캔
5. 공급사 라벨 OCR
6. 두 라벨 비교
7. 정상 → 해당 WMS 순번 처리 완료
8. 확인 필요 → 검토대기
9. Pallet 창고 이동
10. 다음 Pallet 반복

차량이 바뀌어도 같은 관리번호의 미완료 순번은 계속 이어서 처리한다.

## 5. Pallet별 필수 관리키

가능하면 다음 조합을 개별 Pallet의 고유키로 사용한다.

- 관리번호 또는 입고번호
- WMS Pallet 순번 / 용기번호
- 품목코드

예:
26004032 / 0001
26004032 / 0002
...
26004032 / 0048

같은 관리번호 + 같은 순번이 다시 인식되면 중복으로 경고한다.

## 7. 검증 규칙

### WMS 기준
- 인식한 관리번호가 현재 선택 품목과 같은지
- 품목코드 일치 여부
- WMS 표시수량이 포장단위와 맞는지
- Pallet 순번이 허용 범위 내인지
- 동일 순번 중복 여부

### 공급사 라벨 기준
- 품명/별칭 일치
- 수량 일치
- 공급사 Pallet No. 인식
- 제품/규격 일치

### 종료 조건
하나의 품목 관리번호는 WMS 포장수만큼 Pallet이 처리되어야 완료로 본다.

예:
관리번호 26004032
포장수 48
→ 고유 WMS 순번 48건이 모두 처리되어야 완료

## 8. 예외

### 실제 입고가 WMS 포장수보다 적은 경우
임의로 완료 처리하지 않는다.
미입고/잔량 상태로 남기고 사유를 기록한다.

### 부분 Pallet
입하량 ÷ 포장단위 계산값보다 WMS 포장수를 우선한다.
실제 운영에서는 부분 Pallet 등 예외 가능성이 있으므로 계산식은 검산용으로만 사용한다.

### 여러 차량
차량 1대당 약 12 Pallet이라 하더라도 48 Pallet 관리번호는 여러 차량에 걸쳐 이어질 수 있다.
차량이 바뀌어도 관리번호 진행률은 유지한다.

## 9. 현장 성능 검증 단위

기존 12 Pallet 1대 테스트만으로는 부족하다.

최소 아래 3단계로 검증한다.

1. 차량 1대 연속 처리: 약 12 Pallet
2. 하나의 관리번호 완주: 최대 48 Pallet 수준
3. 실제 일일 피크 수준: 약 80~120 Pallet 연속 누적

측정:
- Pallet별 OCR 시간
- 촬영~저장 시간
- 재시도율
- 검토대기 누적
- 중복 순번
- 누락 순번
- 차량 변경 후 진행률 유지 여부

## 10. 기존 차량 Session 설계 처리

이전의 "차량 입고 Session"을 상위 관리단위로 두는 설계는 폐기한다.

새 기준:
- 상위: WMS 입하실적
- 중간: 품목 관리번호
- 하위: Pallet 순번
- 차량: 선택적 참고정보
